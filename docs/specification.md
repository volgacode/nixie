# Спецификация языка программирования Nixie

## 1. Введение

Nixie — минималистичный императивный язык программирования со строгой статической типизацией. Синтаксис близок к C.

Программа на Nixie состоит из одного файла с расширением `.nix`.

Особенности языка:

* поддержка целочисленной арифметики;
* блоки кода заключаются в фигурные скобки;
* встроенные функции и средства ввода-вывода.

## 2. Лексика

### Идентификаторы

Идентификаторы — имена переменных, функций и других сущностей языка.

* **Первый символ:** латинская буква или символ подчёркивания. Идентификатор не может начинаться с цифры.
* **Последующие символы:** латинские буквы, цифры и символ подчёркивания.
* **Регистр:** имеет значение.
* Имена `main`, `print`, `read`, `abs`, `min`, `max` являются идентификаторами, а не ключевыми словами. Их специальное назначение определяется синтаксисом языка.

### Ключевые слова

Ключевые слова представляют собой зарезервированные последовательности символов, имеющие специальное назначение для синтаксиса языка. Список ключевых слов строго ограничен, и эти слова нельзя использовать как идентификаторы. Регистр имеет значение.

| Категория                | Ключевые слова и назначение                                                                             |
|--------------------------|---------------------------------------------------------------------------------------------------------|
| **Типы данных**          | `bool` (логический) · `int` (целое число) · `string` (строка)  · `array` (массив фиксированного размера)|
| **Управление потоком**   | `if` (условие) · `else` (иначе) · `while` (цикл) · `for` (цикл со счётчиком)                            |
| **Функции и возвраты**   | `void` (пустой тип) · `return` (возврат из функции)                                                     |
| **Структуры**            | `struct` (структура)                                                                                    |
| **Литералы и константы** | `true` (истина) · `false` (ложь)                                                                        |

### Числовые литералы

Числовой литерал (`int_literal`) — непустая последовательность десятичных цифр `0`–`9` без знака. Отрицательные числа записываются с помощью унарного оператора `-`.

* **Ведущие нули:** допускаются.
* **Диапазон:** от 0 до 2 147 483 647. Значение 2 147 483 648 допускается только непосредственно после унарного минуса. Пробельные символы между минусом и литералом допускаются, круглые скобки — нет. Контроль диапазона выполняется парсером.
* **Тип:** `int` — 32-битное целое число со знаком, от −2 147 483 648 до 2 147 483 647.

### Строковые литералы

Строковый литерал начинается и заканчивается двойной кавычкой. Внутри литерала допустим любой символ Unicode, кроме `"`, `\`, перевода строки (LF) и возврата каретки (CR). Эти четыре символа задаются только управляющими последовательностями, а символ `\` начинает такую последовательность:

* `\"` — двойная кавычка;
* `\\` — обратный слэш;
* `\n` — перевод строки (Line Feed);
* `\r` — возврат каретки (Carriage Return);
* `\t` — горизонтальная табуляция (Horizontal Tab).

Любая другая последовательность после `\` недопустима.

### Список пробельных символов

| Символ                        | Обозначение | Код  |
|-------------------------------|-------------|------|
| Пробел                        | SP          | 0x20 |
| Горизонтальная табуляция      | HT          | 0x09 |
| Перевод строки                | LF          | 0x0A |
| Возврат каретки               | CR          | 0x0D |
| Form feed                     | FF          | 0x0C |

### Комментарии

* Однострочный комментарий начинается с // и продолжается до символа LF, CR или конца файла.
* Внутри комментария допустим любой символ, кроме символов окончания строки.

### Операторы и прочие лексемы языка

| Категория                    | Токены                      |
|------------------------------|-----------------------------|
| **Присваивание**             | `=`                         |
| **Сравнения**                | `==` `!=` `<` `<=` `>` `>=` |
| **Логические**               | `&&` `\|\|` `!`             |
| **Арифметические**           | `+` `-` `*` `/`             |
| **Группировка**              | `(` `)` `{` `}`             |
| **Индексация**               | `[` `]`                     |
| **Доступ к полям структуры** | `.`                         |
| **Разделители**              | `,` `;`                     |

### Конец файла

При достижении конца файла лексер выдаёт токен `end_of_file`.

## 3. Синтаксис

* Программа состоит из единственной функции `int main()` без параметров, являющейся точкой входа в программу.
* Функция `main` определяется пользователем, не является встроенной и не может быть вызвана из программы.
* Тело функции `main` — блок из последовательности инструкций, возможно пустой.

### Грамматика ISO EBNF (ISO/IEC 14977)

Символы `int_literal` и `end_of_file` — терминалы, обозначающие лексемы из раздела 2.

```ebnf
program = "int", "main", "(", ")", block, end_of_file ;

block = "{", { statement }, "}" ;

statement = print_statement | expression_statement ;

print_statement = "print", "(", expression, ")", ";" ;

expression_statement = expression, ";" ;

expression = additive_expression ;

additive_expression = multiplicative_expression, { ( "+" | "-" ), multiplicative_expression } ;

multiplicative_expression = unary_expression, { ( "*" | "/" ), unary_expression } ;

unary_expression = "-", unary_expression | primary_expression ;

primary_expression = int_literal | "(", expression, ")" | builtin_call ;

builtin_call = read_call | abs_call | min_max_call ;

read_call = "read", "(", ")" ;

abs_call = "abs", "(", expression, ")" ;

min_max_call = ( "min" | "max" ), "(", expression, ",", expression, ")" ;
```

### Приоритет и ассоциативность операторов

| Приоритет  | Операторы   | Назначение                       | Ассоциативность |
|------------|-------------|----------------------------------|-----------------|
| 1 (высший) | `-` унарный | смена знака                      | правая          |
| 2          | `*` `/`     | умножение, целочисленное деление | левая           |
| 3 (низший) | `+` `-`     | сложение, вычитание              | левая           |

* Результат целочисленного деления округляется к нулю. Деление на ноль является ошибкой выполнения.
* Если результат арифметической операции или функции `abs` выходит за диапазон типа `int` - возникает ошибка выполнения.

### Встроенные функции

* Все аргументы встроенных функций имеют тип `int`.
* Функция `print` не возвращает значения и может использоваться только как самостоятельная инструкция. Остальные встроенные функции возвращают значение типа `int` и могут использоваться в выражениях.

| Функция       | Действие                                                                        |
|---------------|---------------------------------------------------------------------------------|
| `print(x)`    | выводит `x` в десятичной записи, за которым следует символ перевода строки (LF) |
| `read()`      | читает одну строку стандартного ввода и возвращает записанное в ней число       |
| `abs(x)`      | возвращает модуль числа                                                         |
| `min(a, b)`   | возвращает меньшее из двух чисел                                                |
| `max(a, b)`   | возвращает большее из двух чисел                                                |

Функция `read()` игнорирует начальные и конечные пробельные символы. Строка должна содержать непустую последовательность десятичных цифр с необязательным знаком `+` или `-` перед ней. Несоответствие этому формату, выход числа за диапазон типа `int` или достижение конца ввода приводят к ошибке выполнения.

### Выполнение программы

* Инструкции выполняются последовательно.
* Порядок вычисления операций определяется приоритетом и ассоциативностью операторов. Операнды бинарных операций и аргументы встроенных функций вычисляются слева направо. Результат самостоятельного выражения отбрасывается.
* При обнаружении синтаксической ошибки или ошибки выполнения интерпретатор немедленно прекращает работу.
* Выполненные до обнаружения ошибки операции ввода и вывода не отменяются.

### Коды завершения интерпретатора

Диагностические сообщения об ошибках исходной программы имеют формат:

`<файл>:<строка>:<столбец>: <тип ошибки>: <сообщение>`

* Нумерация строк и столбцов начинается с 1.

| Код | Назначение                                          |
|-----|-----------------------------------------------------|
| `0` | Успешное завершение программы (неявно)              |
| `1` | Синтаксическая ошибка или ошибка выполнения         |
| `2` | Ошибка аргументов командной строки или чтения файла |
