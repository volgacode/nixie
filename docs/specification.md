# Спецификация языка программирования Nixie

## 1. Введение

Nixie — минималистичный императивный язык программирования со строгой статической типизацией. Синтаксис близок к C.

Программа на Nixie состоит из одного файла с расширением `.nix` в кодировке UTF-8.

Особенности языка:

* язык строго типизирован;
* переменные объявляются явно с указанием типа;
* императивный, процедурный стиль программирования;
* присутствуют арифметические и логические операторы и операторы сравнения;
* блоки кода заключаются в фигурные скобки;
* ветвление осуществляется через if/else, циклы while, for и инструкции к ним.

## 2. Лексика

### Идентификаторы

Идентификаторы называют переменные, функции и другие сущности, определяемые программой.

* **Первый символ:** латинская буква или символ подчёркивания. Идентификатор не может начинаться с цифры.
* **Последующие символы:** латинские буквы, цифры и символ подчёркивания.
* **Регистр:** имеет значение.

### Ключевые слова

Ключевые слова представляют собой зарезервированные последовательности символов, имеющие специальное назначение для синтаксиса языка. Список ключевых слов строго ограничен, и эти слова нельзя использовать как идентификаторы. Регистр имеет значение.

| Категория                | Ключевые слова и назначение                                                                  |
|--------------------------|----------------------------------------------------------------------------------------------|
| **Типы данных**          | `bool` (логический) · `int` (целое число)                                                    |
| **Управление потоком**   | `if` (условие) · `else` (иначе) · `while` (цикл) · `for` (цикл со счётчиком)                 |
| **Функции и возвраты**   | `void` (пустой тип) · `return` (возврат из функции)                                          |
| **Литералы и константы** | `true` (истина) · `false` (ложь)                                                             |

### Числовые литералы

Числовой литерал(int_literal) — непустая последовательность десятичных цифр `0`–`9` без знака. Отрицательные числа записываются с помощью унарного оператора `-`.

* **Ведущие нули:** допускается использование ведущих нулей.
* **Диапазон литерала:** от 0 до 2 147 483 648. Литерал 2 147 483 648 допустим только как операнд унарного минуса. Контроль диапазона выполняется парсером.
* **Тип:** значение имеет тип int (32-битное целое со знаком, от -2 147 483 648 до 2 147 483 647).

### Список пробельных символов

| Символ                        | Обозначение | Код  |
|-------------------------------|-------------|------|
| Пробел                        | SP          | 0x20 |
| Горизонтальная табуляция      | HT          | 0x09 |
| Перевод строки                | LF          | 0x0A |
| Возврат каретки               | CR          | 0x0D |
| Form feed                     | FF          | 0x0C |

### Операторы и прочие лексемы языка

| Категория               | Токены                      |
|-------------------------|-----------------------------|
| **Присваивание**        | `=`                         |
| **Сравнения**           | `==` `!=` `<` `<=` `>` `>=` |
| **Логические**          | `&&` `\|\|` `!`             |
| **Арифметические**      | `+` `-` `*` `/`             |
| **Группировка**         | `(` `)` `{` `}`             |

### Конец файла

При достижении конца файла лексер выдает токен EOF(end_of_file).

## 3. Синтаксис

Программа состоит из единственной функции `main()` без параметров.
Её тело — блок из последовательности инструкций, возможно пустой.
Поддерживается только тип `int`; `bool`, `void`, переменные, пользовательские функции, ветвления и циклы пока на 2 итерации не поддерживаются.

### Грамматика ISO EBNF (ISO/IEC 14977).

Специальные последовательности `end_of_file` и `int_literal` обозначают лексемы из раздела 2. Лексика.

```ebnf
program = "void", "main", "(", ")", block, end_of_file ;

block = "{", { statement }, "}" ;

statement = print_statement | expression_statement ;

print_statement = "print", "(", expression, ")", ";" ;

expression_statement = expression, ";" ;

expression = additive_expression ;

additive_expression = multiplicative_expression, { ( "+" | "-" ), multiplicative_expression } ;

multiplicative_expression = unary_expression, { ( "*" | "/" ), unary_expression } ;

unary_expression = "-", unary_expression | primary_expression ;

primary_expression = int_literal | "(", expression, ")" | builtin_call ;

builtin_call = read_call | abs_call | min_max_call ;

read_call = "read", "(", ")" ;

abs_call = "abs", "(", expression, ")" ;

min_max_call = ( "min" | "max" ), "(", expression, ",", expression, ")" ;
```

### Приоритет и ассоциативность операторов

| Приоритет  | Операторы   | Назначение                       | Ассоциативность |
|------------|-------------|----------------------------------|-----------------|
| 1 (высший) | `-` унарный | смена знака                      | правая          |
| 2          | `*` `/`     | умножение, целочисленное деление | левая           |
| 3 (низший) | `+` `-`     | сложение, вычитание              | левая           |

### Встроенные функции (являются идентификаторами)

| Функция                           | Действие                                                                  |
|-----------------------------------|---------------------------------------------------------------------------|
| `print(int)`                      | выводит параметр в десятичной записи и перевод строки (LF)                |
| `read(int)`                       | читает одну строку стандартного ввода и возвращает записанное в ней число |
| `abs(int)`                        | возвращает модуль числа                                                   |
| `min(int, int)`                   | возвращает меньшее из двух чисел                                          |
| `max(int, int)`                   | возвращает большее из двух чисел                                          |
