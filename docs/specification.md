# Спецификация языка программирования Nixie

## 1. Введение
Nixie - минималистичный императивный язык программирования.
Программа на Nixie состоит из одного файла с расширением .nix в кодировке UTF-8 и имеет точку входа — функцию main.

Особенности языка:

весь код располагается в одном файле;
точкой входа является функция main;
язык строго типизирован: числовой тип int, строковый тип string и логический тип bool;
Переменные обьявляются явно с указание типа;
императивный, процедурный стиль програмирования;
классов в языке нет;
присутствуют арифметические, логические и операторы сравнения;
ввод/вывод в программу поддерживается через функции: str_print, int_print, bl_print, int_read, str_read;
комментарии указываются после символов - //;
блоки кода заключаются в фигурные скобки;
ветвление осуществляется через if/else, циклы while, for и инструкции к ним;
есть поддержка массивов фиксированого размера, а также поддержка структур для групировки данных;

## 2. Лексика

Идентификаторами являются любой последовательностью допустимых символов в кодировке UTF-8.
Ключевыми словами являются определенной последовательностью допустимых символов в кодировке UTF-8, их список строго ограничен.
Ключевые слова зарезервированы для однозначности синтаксических правил.
Регистр идентификаторов и ключевых слов имеет значение.

В файле допускаются символы:
1. Латинские буквы (a-z, A-Z), цифры (0-9).
2. Символ подчёркивания (_)
3. Набор спецсимволов для операторов.

### Список пробельных символов

| Символ                        | Обозначение | Код  |
|-------------------------------|-------------|------|
| Пробел                        | SP          | 0x20 |
| Горизонтальная табуляция      | HT          | 0x09 |
| Перевод строки                | LF          | 0x0A |
| Возврат каретки               | CR          | 0x0D |
| Form feed                     | FF          | 0x0C |

### Комментарии
Начинаются с /* и заканчиваются на */, или начинаются на // и заканчиваются переносом строки.
Вложенные комментарии не допускаются.

### Ключевые слова
bool, else, true, false, if, int, null, true, void, while, for, string, return, struct

Список лексем, используемых в роли операторов выражений: =, ==, !=, <, <=, >, >=, &&, ||, !, +, -, *, /, .
Список прочих лексем: [, ], (, ), {, }, ,, ;

Ключевые слова языка.

| Категория                | Ключевые слова и назначение                                                                  |
|--------------------------|----------------------------------------------------------------------------------------------|
| **Типы данных**          | `bool` (логический) · `int` (целое число) · `string` (строка)  · `array` (статический массив)|
| **Управление потоком**   | `if` (условие) · `else` (иначе) · `while` (цикл) · `for` (цикл со счетчиком)                 |
| **Функции и возвраты**   | `void` (пустой тип) · `return` (возврат из функции)                                          |
| **Структуры**            | `struct` (объявление структуры)                                                              |
| **Литералы и константы** | `true` (истина) · `false` (ложь) · `null` (нулевая ссылка)                                   |

Операторы и прочие лексемы языка.

| Категория               | Токены                      |
|-------------------------|-----------------------------|
| **Присваивание**        | `=`                         |
| **Сравнения**           | `==` `!=` `<` `<=` `>` `>=` |
| **Логические**          | `&&` `||` `!`               |
| **Арифметические**      | `+` `-` `*` `/`             |
| **Доступ**              | `.`                         |
| **Индексация и доступ** | `[` `]`                     |
| **Группировка**         | `(` `)` `{` `}`             |
| **Разделители**         | `,` `;`                     |
